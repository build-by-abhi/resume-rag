# Python dependencies for the Resume RAG API.

#   pip install -r requirements.txt

# Version policy: ranges, not exact pins.
# A few packages here ship compiled wheels (pydantic-core, psycopg-binary) and a
# hard pin means the project stops installing the day your Python releases. These
# ranges stay inside one major version, so behaviour is stable while the install
# still works on Python 3.11 through 3.14. For a deployable app you would pin
# exactly with a lock file (pip-tools / uv) and upgrade deliberately.
# ===========================================================================
